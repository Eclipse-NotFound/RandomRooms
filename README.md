# RandomRooms v8.0

为 Remains 1.02 从零生成建筑空间的模组。

## 使用

更新后重启游戏，回城再进入新的随机土地。已经载入的旧地图不会自动变成新版。

- **F1**：进入随机冒险。初始 5×5，靠近右侧或底部时继续生成新列、新行。
- **F2**：回城。
- **F4**：在随机冒险中进入新的深度层。
- **F5**：进入包含四种主题的展示馆。

## v8 的变化

房间宽度、层高、分隔和相互连接共同生成，不再套用六张固定坐标骨架。房内可以有不同数量的回环、分支与附室；办公室、仓储、维修、居住空间按用途摆放原版家具。

所有实际开放边口均可进出。左右边口分布于不同高度，上下边口通常错开，不指定统一的穿房路线，也不随进入方向重排房间。新邻居与旧房共享预留接口，扩张保留旧布局。

门、活板门与玻璃窗使用原版交互和碰撞。生成时检查净空、梯子落脚、空间可返回性及边口匹配；普通内部下降梯避开下边界接口。

- [六种空间与实际四入口样本](design/generator-v8-review.html)
- [本次验证与发布记录](knowledge/experiments/generator-v8-validation-2026-09-13.md)

结构验证覆盖 1,280 间单房样本、两张各 144 间的地图及 cook 保护。F1 四方向往返和内部遍历 33 / 33；F5 三方向往返和内部遍历 34 / 34。右下扩张实测至 8×8，进入新列、新行后均能返回，原来的 25 间房保持不变。

现有构造仍偏直角建筑，局部摆设和生活痕迹可以继续丰富。未穷尽所有种子，未验证联机或极长时间扩张的内存上限。

## 构建与回滚

构建使用 `build/build-v7.ps1 -OutputName RandomRooms-v8-candidate.swf`；脚本名沿用既有名称，产物在 build 中，发布按工作区门禁执行。

正式入口固定为 `release/RandomRoomsMod.swf`。本机 v7.1 备份为 `build/release-backups/RandomRoomsMod_before_v8_20260913.swf`；将它复制回正式入口并重启即可回滚。游戏主 SWF 和真实存档没有修改。
