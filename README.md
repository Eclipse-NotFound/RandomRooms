# RandomRooms v9.0

为 Remains 1.02 从零生成建筑空间的模组。

## 使用

更新后重启游戏，回城再进入新的随机土地。已经载入的旧地图不会自动变成新版。

- **F1**：选择工厂、废弃避难厩、下水道、城市废墟，或随机选择。初始 5×5，靠近右侧或底部时继续生成新列、新行。
- **F2**：回城。
- **F4**：在随机冒险中进入新的深度层，保持本次选择的场景。
- **F5**：选择一类场景，进入该场景的展示馆。

选择界面支持鼠标和数字键 1–5；Esc 取消。一次探索始终保持同一场景，按 F2 回城后可重新选择。

## v9 的变化

四类场景分别决定空间关系、用途、墙面、门窗、设施、灯光、背景和音乐：

- **工厂**：工作大厅、仓储与附室，厂房窗、混凝土墙、设备线和检修平台。
- **废弃避难厩**：居住、行政、服务舱室与公共空间，金属墙板、专用门窗和钢梁。
- **下水道**：渠池、泵房和检修通路，连续管线、潮湿墙面与真实污水。开放入口之间保留干路，涉水探索可选。
- **城市废墟**：楼体、街道与屋顶交错，破损楼层、残留家具和原版城市远景。

同一场景也有多种构造。放不下完整家具组合时，改用符合当前场景与用途的小组合。

房间宽度、层高、分隔和相互连接共同生成，不再套用六张固定坐标骨架。房内可以有不同数量的回环、分支与附室；办公室、仓储、维修、居住空间按用途摆放原版家具。

所有实际开放边口均可进出。左右边口分布于不同高度，上下边口通常错开，不指定统一的穿房路线，也不随进入方向重排房间。新邻居与旧房共享预留接口，扩张保留旧布局。

门、活板门与玻璃窗使用原版交互和碰撞。生成时检查净空、梯子落脚、空间可返回性及边口匹配；普通内部下降梯避开下边界接口。

## 构建与回滚

构建使用 `build/build-v7.ps1 -OutputName RandomRooms-v9-candidate.swf`；脚本名沿用既有名称，产物在 build 中，发布按工作区门禁执行。

正式入口固定为 `release/RandomRoomsMod.swf`。本机 v8.0 回滚备份及部署指纹见验证记录。游戏主 SWF 和真实存档没有修改。
