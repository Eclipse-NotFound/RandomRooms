# RandomRooms v13

[English](README.md) · 简体中文

为 Remains 1.02 从零生成建筑空间的模组。

v13 在 v12.3 的真实空间生成上加入危险度 D、价值度 V、特殊威胁、炮塔布防、安保终端选点，以及游戏内调试层。[使用与验证记录](design/v13-content-runtime/validation.md)包含显示图例、规则和回滚信息。游戏内保留 [v12.2](design/partition-preview-v12-2/index.html) 与 [v12.3](design/partition-preview-v12-3/index.html) 对照入口。

## 使用

更新后重启游戏，回城再进入新的随机土地。已经载入的旧地图不会自动变成新版。

- **F1**：选 v13（新版默认）、v12.2 或 v12.3，确认种子，再选择工厂、废弃避难厩、下水道、城市废墟或随机。新探索从第 1 层、5×5 开始，靠近右侧或底部时继续生成新列、新行。
- **F2**：回城。
- **F4**：进入下一层，保持本次选择的版本、种子和场景。
- **F5**：选择版本和场景，进入安全布置的展示馆。
- **Shift+F3**：开关调试层，显示房间用途和 D/V、生成点、当前单位、炮塔防守目标、终端候选接近路与实时枪口朝向。开关状态会保存。

比较时先玩一版，按 F2 回城，再按 F1 切换另一版，保持种子和场景相同。两版会使用相同的地图连接、镜像和街区条件；每次重新选择均回到第 1 层。原版掉落和敌人行为仍有运行时随机。

版本用鼠标选择，场景支持鼠标或数字键 1–5；Esc 取消。种子输入立即用于下一次选择，无须再重启。用“换一组种子”比较另一组布局。

## v13 内容规则

D/V 有合成房整体基调，也有内部房间局部差异；合并空间共享预算。D 影响主要敌群机会、规模与布防，V 影响额外高价值容器机会；两者部分关联，可以出现高危低值或低危高值的房间。敌人强度和实际掉落继续遵循原版场景与探索难度。

动物独立抽样，地雷、蜘蛛地雷、无人机等另走特殊规则，偏向低 D、高 V 和适当盲区。顶装与地面炮塔先检查支撑、机械转角和要守住的门梯，不直接按 D 撒点。部分有炮塔的合成房会安排安保终端，优先有遮挡、能接近的操作位；原版终端控制整间合成房内所有炮塔。

调试实线表示当前枪口朝向，不是命中预测。空心生成点与实心活动单位分开显示。低 D 不保证绝对安全，原版容器的暗雷、开箱事件和战斗后变化仍然存在。

## 保留的分区对照

- **v12.2**：按用途随机分配矩形房间，数量、尺寸、位置与层高有变化，部分房间组成对齐的楼层。
- **v12.3**：在此基础上减少分隔房数，加入厚墙、基座和压顶；以横向拆墙为主，少量跨层合并，形成多个矩形连成的空间。

两版均保留原版门、活板门、窗、家具、敌人及通用探索物体，并按四类场景分别配置。

## v11.1 的变化

- 参考对应原版场景，分别配置材料、家具、敌群及设施，保留原版合理共用。
- 缩小普通功能房、增加附室与紧凑家具组合；工厂作业厅、避难厩公共空间及下水道水渠仍保留用途所需的尺度。
- 城市按整张地图组织建筑组、街巷和屋顶，楼内区分住宅、办公、商业与坍塌空间；向右、向下扩张延续原有街区。

## v10 的变化

随机房现在包含原版的通用探索内容，并按场景、房间疏密和深度刷新：

- 普通敌群、水生生物、不同型号炮塔、机器人舱和警报器。
- 地雷、捕兽夹、尖刺、罐头警报，以及配有武器的绊线、踏板和激光机关。
- 可用的机器人控制终端、保险箱解锁终端、资料终端和奖励开关。
- 武器、弹药、医疗、工具与其他原版奖励容器；工作台、化学台、炉灶，以及少量通用商人和医生。
- 场景适用的辐射桶、局部放电设备等环境危险；整房通电开关初始关闭。

容器掉落、敌人行动、拆除和黑入使用原版规则。终端和机关有实际配套目标，奖励开关不会锁住必经路线。出生房和展示馆保留安全布置；扩张保留旧物体和已领取状态。剧情 NPC、任务专属装置与首领不进入本轮普通刷新。

## 四类场景

四类场景分别决定空间关系、用途、墙面、门窗、设施、灯光、背景和音乐：

- **工厂**：工作大厅、仓储与附室，厂房窗、混凝土墙、设备线和检修平台。
- **废弃避难厩**：居住、行政、服务舱室与公共空间，金属墙板、专用门窗和钢梁。
- **下水道**：渠池、泵房和检修通路，连续管线、潮湿墙面与真实污水。开放入口之间保留干路，涉水探索可选。
- **城市废墟**：楼体、街道与屋顶交错，破损楼层、残留家具和原版城市远景。

同一场景也有多种构造。放不下完整家具组合时，改用符合当前场景与用途的小组合。

房间宽度、层高、分隔和相互连接共同生成，不再套用六张固定坐标骨架。房内可以有不同数量的回环、分支与附室；办公室、仓储、维修、居住空间按用途摆放原版家具。

所有实际开放边口均可进出。左右边口分布于不同高度，上下边口通常错开，不指定统一的穿房路线，也不随进入方向重排房间。新邻居与旧房共享预留接口，扩张保留旧布局。

门、活板门与玻璃窗使用原版交互和碰撞。生成时检查净空、梯子落脚、空间可返回性及边口匹配；普通内部下降梯避开下边界接口。

## 构建与回滚

构建使用 `build/build-v7.ps1 -OutputName RandomRooms-v13-next.swf`；脚本名沿用既有名称，产物在 build 中，发布按工作区门禁执行。

正式入口固定为 `release/RandomRoomsMod.swf`。本机回滚备份及部署指纹见验证记录。游戏主 SWF 和真实存档没有修改。
