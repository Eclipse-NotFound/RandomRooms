局部 D/V

整体值＋用途偏置＋共同变化＋各自随机变化。先按拆墙后的房间分配，避免给每个原始矩形重复一整份内容。每条随机来源由种子和空间位置固定。

有威胁的偶遇

特殊威胁机会＝6%＋60%×(1−D)⁰·⁸×V¹·²，再乘机会滑块。关闭偏好后为固定 18%。这是设计原型的参数，不是原版掉率；空间、入口、生态和累计压力仍会过滤结果。

遮挡与防守

地雷类优先选择从部分相邻接近点被墙或示意遮挡物挡住的位置。地面和天花板炮塔必须覆盖门梯连接点，完整可转向范围不能射入入口缓冲区。顶炮需要实体顶面支撑；红色站位格显示潜在射界，虚线只表示瞄准方向。未调用原版 AI 或武器。

安保终端选点

在带炮塔的合成房按机会抽取，最多一处。优先控制室、检修间、办公室及遮挡旁；操作空间避开全部炮塔潜在射界，至少一个入口须有避开射界的近似路线。其他入口分别显示结果，不预设统一进房方向。终端周围不紧贴生成敌人或地雷。

原版对应

原版 term1 对整 Location 尝试 hack；普通效果关闭炮塔，相关能力可改为友方。天花板炮塔的 30°／150° 是待机扫描目标，并非完整转角上限。这里保守选择向下布防，并按更宽的可转向范围检查风险。

边界

实时布局为独立浏览器模拟；实际导出模式仅复用 v12.3 的地形、分区与接口。两种模式的 D/V、敌人、家具与奖励均由本页重新模拟。连接图连通不等于原版角色可走通；物体符号和风险分数不代表实测伤害或掉落价值。
