# DEC-0004 —— "灵性"路线：反均匀三步走（2026-08-28）

状态: **已确认**（用户 2026-08-28 批准归档并执行）

## 背景

v5.6 分层大厅解决结构问题后，实机观感仍"缺乏原版精心设计的灵性"。

## 决策

采用"反均匀"路线，三步走（design/room-soul-plan.md）：
1. 第一刀：空房美学 + 分区纹理 + 墙面叙事 + 氛围 options
2. 第二刀：房间个性系统（个性向量驱动全部密度参数）
3. 第三刀：视觉锚（主角先行），之后叠加进深序列/遭遇编排

## 关键取舍（为什么不是别的）

- **不做物件组合语义表**：语料实证共现提升度仅 1.2-1.5x——原版物件组合
  本身近乎随机，语义绑定假设不成立；堆叠假设同样被否（最近邻距离≈随机期望）。
  灵性在"层"（方差/分区/序列/锚点），不在"点"（物件选择/成簇）。
- **不先做黄金路径**：BFS 主路分析实现重、玩家感知弱；进深序列（轻量梯度）
  可后期以更低成本覆盖同类体验。
- **不做对称房**：语料无强对称证据；程序对称易生硬，与"学规律"支柱冲突风险。
- **原型变异不深化**：P0 模板变异已在混合池运行，整房模板复用有 v3.6 拼贴教训；
  合成房的灵性从方差与锚点来，不从模板来。

## 影响

- RRSynth 物件放置改两阶段（锚优先）；generate() 输出 <options> 增 music/fon；
- 全部改动在合成器内部，房池 XML 接口与 validateRoom 兼容性不变；
- 每步独立可验证（diag-skeleton.py 结构层 + synth-v54-verify.py 不变式 + F5 实机）。
