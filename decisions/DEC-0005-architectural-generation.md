# DEC-0005 — 从零生成建筑空间，再按用途布置

状态：已接受。用户于 2026-09-10 查看 A/B/C 原型对照后明确选择「采用 C，继续完善并实现正式生成器」。

## 背景

v6.6 合成房仍不自然。2026-09-10 的独立 AS3 基线实跑显示固定底边开孔仍存在；原版普通房广泛使用平台、梯子和斜坡，而旧生成器把这些排除在装饰之外，再以连通修补挖穿结构。对全部墙格或物件做独立随机选择，破坏了连续材料和局部用途关系。

120 间原版普通房的研究、32 个原型 C、固定房真实渲染与公开 Ctr 移动采样是本次决策依据。对照入口：`design/style-review-2026-09-10.html`；原型是可丢弃实验，正式实现为 AS3。

## 决策

- 以主厅、附室、工作区、分层办公室、仓储夹层和维修空间等关系生成 25×48 合成房。地形从零生成，不读取原版整房或地形片段作为生成输入。
- 结构完成后再放家具。按用途选成组桌柜、控制设施、管线、仓储与休息角；先检查整组的空间、支撑和门梯保留区。不足时选较小组或留空。
- 四主题使用原版有证据的材料组合：stable 的 J 墙身/K 边带；sewer 的 L 湿墙与检修区；plant 的 C 主体与裸底大厅；mane 的 N 主体和 C/D 背景。装饰不重新随机改写结构瓦片。
- 显式填写原版 22 位边界连接记录。普通房只声明底层左右开口；跨楼层使用有全高梯链的专用竖井房。两个自有土地使用原版 conf=4 的两侧竖井排布，供足不重复抽样的 vert 房与独立端点。
- F1 自有冒险土地采用完整 C 房池，每次进入统一一个主题；F5 展示馆展示四主题。原版土地仍走原有路线。C 房不再接受 RRCook 的瓦片变异或重复扩池。
- 出生、敌人标记、进深出口与旅行入口继续使用原版机制。完整世界种子确定性及联机不属于本次验证承诺。
- 用户随后明确选择保留向右、向下无限扩张。初始 5×5 只作为起点；靠近边缘时提前构造新列/行，每四列保持一条竖井，新增空间走完整连接、对象装配和地图更新流程。F4 进深继续保留，不能用有限层替代用户要求的二维扩张。

## 比较与取舍

| 方案 | 原型结果 | 取舍 |
|---|---|---|
| A：清理旧输出材料噪点 | 画面变干净，但巨大空腔和机械结构保留 | 可作诊断，不能承担正式重写 |
| B：原版局部空间重组 | 保留细节；严格边界/对象约束下合格组合很少，当前改动幅度小 | 保留实验，不作为生成器来源 |
| C：建筑空间关系 | 已出现完整平台、梯井、附室与用途区；可继续扩展房型和设施 | 用户选定，正式实现 |

C 当前只有六类普通布局，仍可能看出共同结构；这是可继续扩充的内容边界。规则错误可能影响一批种子，因此以真实 AS3 批量导出、变异后检查和原版游戏移动采样共同验证。改变生成器只影响重新生成的自有土地，不修改游戏 SWF 或真实存档文件；回退可恢复上一版模组 SWF。

## 对旧结论的限定

本决策取代 DEC-0004 中「不做物件组合语义表」的方向判断。整房共现统计接近随机，不能据此推断原版局部摆设没有用途关系。本次直接核对到桌柜、连续管线、控制台与厨房的局部组合。旧决策保留作为历史，不改写其当时证据。

术语继续使用 MEMORY 的约定：土地是一次旅行的完整地图，合成房是 25×48 的土地格，房间是其内部功能空间，通道是内部连接。
