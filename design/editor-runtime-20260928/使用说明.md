# RandomRooms v13.1：游戏快照与编辑器审查

这版把实际生成的合成房接入地图编辑器，并修正终端、墙上按钮和壁式保险箱贴地的问题。生成器仍是 v13 的结构与 D/V 规则，v12.2、v12.3 对照选项保留。

## 开始查看

1. 完全退出并重启游戏和地图编辑器。游戏中先 F2 回城，再 F1 生成新地图；已经生成的旧地图不会自动改变物品位置。
2. 在随机探索或展示馆中按 **Shift+F5**。提示出现后，当前已生成的整张地图已导出，包括向右、向下扩张的合成房。
3. 启动游戏目录的 **地图编辑器.vbs**，在底部“预渲染”旁点击 **随机房审查**。面板自动读取最近一次导出；以后可点击“读取最新导出”刷新。
4. 点击右侧地图坐标，或使用上一间、下一间和四向邻房按钮。勾选用途/D·V、物体生成点、布防与接近路、相邻接口，点击物体标记查看详细信息。

导出保存在 `mods/RandomRooms/exports/review/`。每次保留独立 XML，`latest.xml` 是最近一次的副本。“选择快照”可以重看更早的探索；“导出当前图”保存带当前叠层的 PNG。滚轮缩放，拖动画面移动，“适合窗口”复位。

## 高度与叠层如何理解

- 新生成的 term1/2/3、knop1/3、wallsafe 等适用挂墙物品，比其操作地面高 **40 像素（一格）**。设备安装位和玩家站立位分别检查；为站立操作留出两格身体空间，避开梯子。压力板等地面机关保持原来的放置方式。
- 紫色虚线是炮塔计划防守的位置。青色虚线是安保终端的候选避火接近路，小圈标示设备地面操作位。安保终端仍控制整间合成房的炮塔。
- 蓝色边框表示与已生成邻房的接口配对；橙色表示未配对或地图尚未向该方向扩张。
- 快照记录的是**生成时的设计**。游玩后的破坏、敌人移动、容器消耗不包含在内。编辑器显示原生静态模型，不运行 AI。实际现场枪线请在游戏按 **Shift+F3** 查看。
- 切换叠层不会重抽底图。重新读图、切换房间再返回时，原版未固定的装饰帧和模型外观仍可能变化；不能把这种变化误认作算法改动。

## 比较手动修改

在普通编辑器里打开一份导出的 XML，选择并修改对应房间，再打开审查页、选择同名原房，点“读取编辑稿对照”。审查页可在完整生成原图和当前编辑稿之间切换；橙框标前景格变化，青框标附加层变化。

编辑稿沿用原房的用途、D/V 和布防标记供参照，**这些规划不会因手动拆墙而自动重算**。这一入口不会将编辑稿送回游戏。普通编辑器重编码还会丢失部分生成元数据，草稿应另存，不要覆盖原导出。物体和背景的改动可从两张原生画面比较，目前没有逐物体差异清单。

## 回退与验证记录

发布证据见 [validation.md](validation.md)，安装文件与备份见 [deployment.json](deployment.json)。如需回退，先退出游戏和编辑器，在本模组目录运行 `python build/deploy-editor-review.py --rollback`，再重启。该操作只恢复本次记录的四个目标；若发现后续修改，会停止，避免覆盖其他工作。
