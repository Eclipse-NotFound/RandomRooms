# 原版探索内容接入

用户确认先完整接入可独立运行的通用探索内容；剧情 NPC、任务装置和首领不混入普通随机房。密度问题尚无单独答复，本轮按已说明的默认建议采用疏密变化。四类场景、一次探索固定场景、多方向进入、无限右下扩张和下水道必经干路均沿用。

## 生成顺序与规则

地形和连接先确定，`RRPopulation` 再安排探索内容并预留占地，最后 `RRFurnish` 填充家具。物体避让出口、梯子、门窗、出生位置与已经占用的空间，按地面、天花板、侧壁或水中分别检查。

普通房约 18% 安静、24% 搜索、35% 巡逻、23% 重守。搜索和重守区有额外奖励，敌群数量受深度影响并设上限；不会每房强制出现每类东西。出生房和 F5 展示馆不放敌人与危险设施，容器取消地雷；展示馆也取消锁。

| 类别 | 原版内容与配套 |
|---|---|
| 敌群 | 掠夺者、佣兵、奴隶贩子、斑马、僵尸、变异虫兽、机器人、浮游机器人、水中鱼等，按场景和深度分组选择；高级独角兽、重型机器人等晚一些出现 |
| 防御 | 落地、吊顶、壁挂等炮塔；部分配机器人控制终端；机器人舱和警报器 |
| 奖励 | 普通箱、弹药箱、爆炸物箱、武器箱/武器柜、保险箱、医疗箱、工具箱、书柜、资料终端等；物品由原版掉落系统决定 |
| 终端与开关 | 机器人终端配实际炮塔；解锁终端配可被黑入的可选保险箱；按钮只指向本房可选奖励箱，无任务标记依赖 |
| 陷阱 | 地雷、捕兽夹、尖刺、顶刺、罐头警报；绊线/踏板/激光配枪械机关、落雷或爆炸物；触发器与武器有唯一同房组号 |
| 环境危险 | 工厂和下水道辐射桶，工厂/避难厩局部放电设备，深层下水道广播装置；整房通电开关初始关闭 |

工厂主要是机械防御、掠夺者与设备物资；避难厩是设施守卫、僵尸和居住/医疗物资；下水道是水生及地下生物、污水和维护物资；城市有街区敌群与生活/军用物资。通用资源可以跨场景复用，但不再使用会被原版地图参数重掷成异场景敌人的通用敌群占位符。

## 原版机制核对

依据游戏 1.02 `AllData`、`Location.setObjects/createUnit/createObj`、`Interact.act/actOsn`、`UnitTrigger`、`UnitDamager`、`Mine` 与服务 NPC 的实现。

- `term1` 的 `hack_robot` 控制所在房间机器人；`term2` 的 `hack_lock` 只影响允许被终端控制的锁。终端必须有相应目标。
- `UnitTrigger` 未指定 `allid` 时会自行寻找或兜底生成武器，位置可能超出已规划空间。这里明确同时摆放触发器和武器，并赋同房唯一组号。
- 原版地雷成功拆除使用 `successRemine` 回调；普通机关走 `actFun`。测试不能把两者都当作同一种行动。
- `Location.setDoor` 的 `setNoObj` 会把左右入口向内六格、上下入口三行标成不可放置。原版 `rem` 类物体会被直接省略。内容与家具现在都预留这一区域，保留原版保护机制。
- 水池对家具的预留不能一并排除水生敌人；鱼只允许进入真实水格，仍避让返程梯子。
- 新房内容在 `setObjects` 时由原版类创建。扩张只创建新增房，不重建旧房对象；领取、开锁、拆除等状态由原版实例维护。

验证结果、精确覆盖和限制见 [验证记录](../knowledge/experiments/generator-v10-validation-2026-09-20.md)。这不是所有原版资产的无条件随机抽取：任务触发器、主线 NPC、首领、专用出口和需要独立流程的事件仍不加入。
