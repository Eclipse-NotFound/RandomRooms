# 随机房间生成 v3 规划 —— 场驱动的连续生成（头脑风暴与详细设计）

> 版本: v3 规划（2026-08-19）
> 定位: 取代 v1/v2 的"布景块拼接"，达成"墙由场长出来"的程序化生成。
> 本文是设计规划，未实现；实现按里程碑推进。

---

## 1. 现状诊断（为什么块拼接到头了）

- v1：随机贴块 + 装饰 → 无道路、材质混搭
- v2：道路模板（走廊/大厅）+ 生物群系分组 → 材质统一、有分区，但
  **墙仍是"固定长度 6×4 真实切片的随机组合"**：
  - 块边界处处拼接缝，无法生成连续、有节奏的墙体；
  - 道路是"预留开放带"，不是由墙的轮廓定义——空间松散。
- 本质：**Remains 房间是二元瓦片场**（`_`=空地，A-T=实体墙，后缀=装饰）。
  既是场，正确做法是**用连续数学场定义墙的形状**，而非拼积木。

## 2. 设计原则

1. **连续 > 拼接**：墙线由场（噪声/SDF/分区）连续生成，无"块单元"概念；
2. **路由墙定义**：廊道是"在墙场中挖出的隧道"，不是预留带；
3. **种子确定**：同种子 → 同房（RRSeed 注入）；
4. **约束完备**：25×48、缺口对齐、BFS 可达、字符合法（FCHARS/OCHARS）、
   biome 素材一致、毫秒级生成；
5. **可验证**：离线批量不变式 + 游戏侧构造预检（buildLoc 复现）。

## 3. 参考游戏借鉴

| 游戏 | 策略 | 在本项目落地 |
|---|---|---|
| Minecraft | 噪声场定义形状（生物群系→结构→地表） | 值噪声场 → 双阈值 → 连续弯曲墙带 |
| Lethal Company | 锚点 + 程序挖隧道 + 种子 | 房间=功能锚点图，锚点间算法挖廊道 |

## 4. 核心架构：三层 + 可选增强

```
L1 空间骨架（程序）
   ├─ 房间类型选择：corridor(横向/纵向)/hall/quad(四区)/l(折角)/bunker
   ├─ 功能锚点布置：缺口侧×N、核心开放区、掩体岛群、对象位
   └─ 场合成：值噪声 或 距离场(SDF) 或 Voronoi → 开放区/墙区轮廓

L2 瓦片场（程序）
   ├─ L2a 开放格：biome 地面（`_` + 稀疏后缀装饰，频率按 biome）
   ├─ L2b 墙格：材质场分配墙字符（A/C/K... 按空间位置与噪声）
   │        [可选增强：WFC 用语料 3×3 邻接做连续纹理——墙角/丁字/门窗自然过渡]
   └─ L2c 廊道挖掘：锚点间 A*/直线隧道切墙成路

L3 约束/后处理
   ├─ 缺口统一（行12 / 列23,24）与开口对齐
   ├─ BFS 可达性（孤岛回填）
   ├─ 25×48 / 字符合法（validateRoom）/ options 落位
   ├─ 敌人数值（entip/kolspawn 走 rollEnemies）
   └─ 构造预检（new Location 复现 buildLoc，崩溃丢弃）
```

## 5. 各技法算法细节

### 5.1 值噪声场（primary，用于 corridor/hall 的连续墙带）
```
seed → 生成低分辨率阵 R = (6 行 x 12 列) 随机 0..1（种子 PRNG）
对 25x48 网格逐格：f(x,y) = 双线性插值(R)   [+ 可选 fractal 叠加 2 层 octave]
阈值得三态：
  - f < t_open         → 开放（地面）
  - t_open <= f < t_wall → 边缘（装饰带：既有开也有墙的过渡）
  - f >= t_wall         → 墙体（材质化）
调节 t_wall 控制墙密度（目标 20-35%）；t_open 控制通路宽度。
→ 得到连续、任意弯曲的墙线；配合 5.3 挖廊道保证连通。
```
验证：墙占比在区间、开放区连通（BFS）、墙线连续性（4 邻接墙占比）。

### 5.2 距离场 SDF（用于 bunker/掩体岛）
```
取 n 个掩体中心点 C（随机/按类型布置），对每格 d=min(dist(p,C))；
墙体 = d 在 [r1, r2] 环带（圆/椭圆掩体壁）+ 中心可能开放；
→ 圆形/椭圆连续墙体（地下工事感），可叠加噪声变形（r += A*noise）。
```

### 5.3 程序挖廊道（Lethal Company 式）
```
锚点（缺口起止/核心/门位）之间：
  直线走廊：在两 x/y 之间切宽 2-3 的带（简单、可控）
  或 A*：以"墙越少越好 + 转弯惩罚"在 25x48 上寻路 → 自然弯曲的隧道
挖出的格 → 开放；隧道璧保留墙 → 道路由墙定义。
```

### 5.4 Voronoi 分区（quad/多区房间）
```
随机 3-6 个区心 → 每格归属最近区心（Voronoi）→ 区界（相邻异区）→ 墙；
每区按类型赋功能（hall 区开放 / cell 区密集掩体 / 廊区窄道）；
区之间挖 1-2 个门（对应缺口与功能锚点）。
```

### 5.5 WFC 细化（可选后续，L2b）
```
语料统计 3x3 patch 转移（墙-墙-空-装饰邻接频率）→ overlap WFC 对
墙体区细化 → 连续自然图案（转角/丁字/窗/门框）。
种子确定；失败重试（种子+1）；作为噪声场的"精修层"。
```

## 6. 验收标准（设计师视角）

1. **可读性**：进入房间 1 秒内能分辨：这是走廊/大厅/隔间组——功能分区清晰；
2. **连续性**：无固定长度墙段拼接感（相邻墙格 4-邻接率高、墙线自然弯曲/成角）；
3. **节奏**：开放-压缩交替（走廊收窄→厅放open→掩体小林），不单调不拥挤；
4. **连通**：所有缺口相互可达、无孤岛（BFS 保证）；
5. **统一**：整房单一 biome 材质；装饰密度与语料一致；
6. **多样**：同种子稳定可复现；不同种子/每次进入差异明显；
7. **合规**：25×48、字符合法、构造预检通过、毫秒级（<10ms）。

## 7. 里程碑与风险

```text
M1  场合成器离线原型（值噪声/SDF/Voronoi + 挖廊道）→ 500 房批量不变式
    + ASCII 视觉评估（道路/墙线/密度）
M2  材质场 + 装饰层（biome 一致）→ 离线验证 + 视觉评估
M3  AS3 移植（RRSynth v3）+ 集成（进入级注入/构造预检）→ 实机
M4  WFC 细化（L2b，可选） → 实机对比
```

| 风险 | 对策 |
|---|---|
| 噪声墙"平庸"（太空旷/太密） | 阈值参数 + 语料密度校准 + 双 octave |
| 迷宫化（看不出功能） | Voronoi 分区 + 功能锚点强约束 |
| WFC 生成慢/死锁 | 仅做墙区局部细化；种子重试上限；预算内降级噪声 |
| 与生物群系冲突 | 材质场只取当前房间 biome 组 |

## 8. 与现有体系的衔接

- 合成房仍是普通 rnd 房：进入级注入 → 缺口统一 → cook 变异 → rollEnemies
  → 无限模式/深度循环无缝兼容；
- 展示馆（F5）与 F7 直传（可视测试通道）不变；
- 种子：RRSeed.fork("synth") 逐格 PRNG，同种子同房。

## 9. 开放问题（实现前确认）

1. 目标墙密度/房间复杂度（默认：走廊 25%、大厅 20%、隔间 30% 墙占比）；
2. WFC 细化是否进入 v3 首版（默认延后 M4）；
3. 房间类型分布（corridor/hall/quad/l/bunker 权重）。
