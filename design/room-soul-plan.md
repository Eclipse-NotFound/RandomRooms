# 灵性工程 —— 反均匀三步走（2026-08-28 头脑风暴产出）

> 目标：v5.6 结构达标（开放率/连通/通道）后，解决"缺乏原版精心设计的灵性"。
> 路线取舍见 decisions/DEC-0004；统计实证见 knowledge/discoveries/room-content-statistics.md。

## 灵性的解构（658 房语料实证驱动的重新定义）

直觉假设被数据推翻：原版物件组合近乎随机（共现提升度 1.2-1.5x），同物件
也不成簇（case 同房最近邻 12.6 格 ≈ 随机期望 13.5）。**灵性不在物件层面，
在"层"上**——四个真实来源：

| 灵性来源 | 语料证据 | v5.6 现状 |
|---|---|---|
| 方差（房间个性） | 每房物件种类 0-9 波动，10 间全空房 | 每房密度恒定 |
| 分区（视觉/功能区域） | `_R`/`_P` 纹理带区域化 | materialBands 均匀 2×4 |
| 序列（入口→深处节奏） | 进深结构 | 无建模 |
| 锚点（单一视觉主体） | 大件群/结构特征 | 无主角 |

**均匀是灵性的反义词**——手工设计的本质是刻意的不均匀。

## 设计卡 1：房间个性系统

- **pitch**：推开每扇门，先知道这是什么地方。
- **体验定位**：填补"识别"空隙；学方差这个规律（支柱①），不学内容。
- **谱系**：Brogue 地形性格 + Spelunky 分区概率表；改动——性格参数从语料
  分布校准（每房物件种类 0-9 的真实波动），非拍脑袋。
- **机制**：每房抽个性向量（物件密度、留白率、后续扩：材质对比度/锚类型）
  → 驱动物件数量/装饰密度/纹理分区强度 → 玩家 3 秒读出房间性格。
- **MVP**：个性向量 2 维（物件密度、留白/全空）；8 个展示馆房出现
  "一间全空 + 一间密集"的极端对比。
- **验证标准**：盲看 8 房能说出差别；连续生成房的物件种类数方差接近语料。
- **实现**：纯 RRSynth 内部，个性向量在 generate()/v5Skeleton 入口抽取。

## 设计卡 2：视觉锚（主角先行）

- **pitch**：每间房有一个你记得住的东西。
- **体验定位**：制造记忆点；锚从语料 192 种物件的大件池里抽，非新素材。
- **谱系**：Enter the Gungeon 房间焦点物 + 建筑"一个主体"原则。
- **机制**：先放锚（同 id 大件群，占房面积 10-20%）→ 其余物件围绕退让 →
  玩家进房视线先落在锚上。
- **MVP**：锚池 3 种（locker 排、mcrate2 堆、table 组），50% 房间出锚。
- **验证标准**：任意一房能说出"主体是什么"；说不出 = 失败。
- **实现**：物件放置改两阶段（锚优先 → 常规物件退让），占地校验复用 footOk。

## 执行路线（三步走）

1. **第一刀**：空房美学 + 分区纹理 + 墙面叙事 + 氛围 options（一轮迭代，全部离线可验证）
2. **第二刀**：房间个性系统（方差成为一等公民，第一刀四项变成它的参数）
3. **第三刀**：视觉锚；之后叠加进深序列/遭遇编排

首个原型 = 卡 1 的 2 维 MVP + 卡 2 的 3 种锚池（"玩家能否感知设计感"最不确定处，F5 一轮验证）。
