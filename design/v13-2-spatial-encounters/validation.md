# v13.2 验证记录

2026-09-28。v13.2 已安装，最终字节的四场景扩张复测及正式加载器冒烟均通过。浏览 [前后对照页](index.html)；规则和原版依据见 [design.md](design.md)。

## 改了什么

- 敌人、炮塔与其他有成本的威胁按实际相通区域共享预算，闭门划开初次接触，有敞开绕路则仍算相通；近邻区域另外检查叠加。主敌人和炮塔锚点相距至少4格。增加普通门的机会，降低主敌群人数与增援点机会，保留原版AI和敌人型号规则。
- 增加局部楼层/建筑翼组合，不再只从全幅共层和递归切块中选择。合并房背景带统一，家具组合左右反排、局部数量和设备间距变化。
- 减少厚块规划面积，在合适实体侧面挖可进入的凹室，部分用原版低耐久F实体封住奖励。封闭时查必经路，打开后查暗格进出与干路；V决定容器档次，不改变地形。

## 同种子样本对照

每场景48间，共192间；v13.1取自上次冻结的真实AS3生成结果，v13.2重新运行正式源码。相同场景、种子和地图坐标，不是HTML另写的近似生成器，也不是原版房池出现概率调查。

厚块统计：内框46×23格中，被至少一个完整5×3实体矩形覆盖的格子并集/1058。它度量明显厚实区域，包含相连承重地形，不等于规划器显式mass预算。

| 场景 | 厚块面积占比：旧→新 | 主敌人＋炮塔平均数量：旧→新 | 相距不足4格的点对：旧→新 |
|---|---:|---:|---:|
| 工厂 | 9.84% → 4.36% | 4.02 → 2.65 | 37 → 0 |
| 废弃避难厩 | 18.94% → 6.99% | 2.75 → 2.06 | 22 → 0 |
| 下水道 | 25.28% → 10.55% | 1.94 → 1.75 | 23 → 0 |

71/192间使用新的建筑翼组合；共38处凹室，其中17处有薄弱封口的隐藏奖励。房间不是每次都强制出现凹室或新结构。数据与统计口径保存于 `metrics.json` / `assess.py`。

- 仅替换 `release/RandomRoomsMod.swf`，原版清单加载器启动3/3案通过：F1/F4/F2/F5、Shift+F3调试和Shift+F5完整导出。测试驾驶器没有手动调用正式模组init；证据 `release-smoke/`。
- 游戏本体、启动描述符、加载清单、编辑器及其审查组件均与安装前指纹一致。备份 `build/release-backups/spaces-v13-2-20260928-215805/RandomRoomsMod.swf` 为原v13.1；部署记录 `deployment.json`，归档索引 `evidence-index.json`。

## 过程中发现并保留的失败

- 第一轮算法检查的E4X筛选访问了无uid家具，触发测试器1065；改显式读取属性后通过。首次输出保存在 `build/spatial-v132/algorithm-first.zip`，不是把该失败当生产生成器错误。
- 初次原生检查仍期待旧 `rrRevision=13`，新版已为13.2；只修检查器，失败档 `version-probe-failed/` 保留。
- 首轮行走器站在低箱子上，却等待箱子下面的地面节点，导致避难厩扩张超时。只在中间路点、确有脚下家具且角色站稳时接受这个高度差；最终目的地条件未放宽，没有写玩家位置。失败 `navigation-failed/`、同一中间候选四场景复测 `growth-intermediate/` 均保留。
- 中间候选有11个悬空/顶装威胁未归属身体通路区域。最终版本补最近无遮挡节点归属并拒绝仍无法归属的威胁，重新完成192间算法与四场景原生内容验证。中间数据 `population/` 和 `build/spatial-v132/pre-sector-fix.zip` 不是最终版本证据。

`build/deploy-v13-2.py` 核对旧安装、候选、生产源码、已冻结算法和原生验证的哈希。游戏本体、编辑器、NativeScene与加载清单都作为只读守卫。备份与最终部署状态以本目录 `deployment.json` 为准；回滚命令为 `python build/deploy-v13-2.py --rollback`，发现其他后续版本会拒绝覆盖。

测试使用独立的 `pferr-style-*` 隐藏AIR实例和新角色；保留实际记录及本机PNG/ZIP，不接触真实存档、不关闭用户进程。PNG/二进制ZIP沿既定规则不进公开Git；文本清单保留其指纹。旧的日期脚本/归档不会被这次复测覆写。

## 尚未证明的事

初始刷新更分散不等于交战后绝不聚集。原版听觉不检查门墙，部分AI能开门，报警、追击、容器潜伏与破坏触发仍可增加战斗压力。没有做长时间实战难度统计，未穷尽种子、全部入口动作、全部武器破墙、联机、DLC或全模组组合。

减少厚块和增加组合不等于彻底消除模板观感；部分狭长走廊、规则家具节奏和城市顶框仍可见。本轮没有实施此前破碎算法调查中的所有建议。预览页是实际样本库；已检查脚本语法、数据与本地资源，不把这些检查说成浏览器交互实测。

使用：完全退出并重启游戏，F2回城后F1选择v13进入新图；旧图不会自动重排。v12.2/v12.3对照仍保留，Shift+F3看调试信息，Shift+F5可导出到已安装的编辑器审查入口。
